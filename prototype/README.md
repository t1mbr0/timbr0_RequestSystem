# Интерактивный прототип RequestSystem

React + TypeScript + Vite. Реализованы вход, список и фильтры, создание, карточка, редактирование, комментарии, смена статуса, удаление с подтверждением, справка и мобильное меню.

## Запуск

```bash
npm install
npm run dev
```

Для демонстрационного входа уже заполнены данные: логин `operator`, пароль `12345`.

Данные сохраняются в `localStorage` текущего браузера. Серверная часть и настоящая аутентификация в этом учебном прототипе не используются.

## Проверка

```bash
npm run build
```

Проверены 13 пользовательских сценариев, отображение при ширине 1440 и 375 пикселей, отсутствие ошибок консоли и HTTP-ошибок.
