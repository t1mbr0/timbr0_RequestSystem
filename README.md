## Назначение

Система предназначена для регистрации обращений, хранения сведений о заявителе, категории и статусе, назначения исполнителя и контроля выполнения заявки. Проект заменяет разрозненный учёт обращений в сообщениях и таблицах единой прозрачной историей работы.

## Основные функции

- регистрация заявки с автоматическим номером;
- разграничение прав администратора, оператора, исполнителя и заявителя;
- поиск и фильтрация по статусу и категории;
- назначение исполнителя и контроль сроков;
- смена статусов по согласованному жизненному циклу;
- комментарии и история изменений;
- просмотр карточки заявки и подтверждение закрытия.

## Структура репозитория

```text
docs/
  TZ.md                    — техническое задание
  ai_log.md                — журнал работы с нейросетью по работам №1–5
  architecture/            — архитектурные решения и диаграммы
  ui/                      — прототип интерфейса и изображения экранов
  database/                — ER-диаграмма и результаты SQL-проверок
  reports/                 — отчёты по лабораторным работам
  screenshots/             — фактические результаты Git и SQL
src/                       — структура будущей реализации по слоям
tests/                     — автоматические проверки базы данных
database/
  schema.sql               — создание схемы с нуля
  seed.sql                 — тестовые данные
  queries.sql              — SELECT, INSERT, UPDATE и DELETE
  requests.db              — учебная SQLite-база
scripts/
  verify_database.py       — воспроизводимая проверка SQL
```

## Проверка базы данных

```bash
python scripts/verify_database.py
```

Скрипт заново создаёт базу из `schema.sql` и `seed.sql`, выполняет `queries.sql`, сохраняет результаты запросов и проверяет ограничения целостности. Для ручного просмотра можно использовать любой клиент SQLite.
